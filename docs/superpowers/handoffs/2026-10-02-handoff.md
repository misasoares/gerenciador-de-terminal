## Pegadinhas do ambiente

- O `cd` do zsh do usuário é uma função que quebra com caminho com espaço: use `builtin cd "<caminho>"`, ou `git -C`.
- O hook RTK reescreve comandos: para ver a saída do vitest, use `rtk proxy npx vitest run --reporter=dot ...`.
- Worktree nova: `npm install --silent`. Se `node_modules/electron/dist` não existir, rode `node install.js` dentro de `node_modules/electron` (o binário às vezes não baixa).
- Instância isolada em segundo plano: `builtin cd "<worktree>" && GT_HOME=/tmp/gt-x npm run dev`, com `run_in_background`.
- Build do app mac: `npm run pack` → `dist/mac-arm64/Gerenciador de Terminal.app`.
- Build Linux (`.deb`, `.rpm`, AppImage x64): `sh scripts/build-linux.sh`, que usa Docker e leva alguns minutos. O amigo Victor usa Arch (AppImage). Pacotes no Arch: `sudo pacman -S --needed fuse2 git openbsd-netcat procps-ng`.
